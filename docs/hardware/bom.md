# Bill of Materials (BOM)

Here is a list of the exact components required to build the Triangle robot. The provided 3D models were specifically designed around the dimensions of these components.

| Component               | Quantity | Description               | Specific Model Used                  |
| :---                    | :---     | :---                      | :---                                 |
| **Microcontroller**     | 1        | RP2350 based, with BLE    | Raspberry Pi Pico 2 W                |
| **BLDC Motor**          | 1        | Actuator (Reaction Wheel) | **GM3506** (with integrated encoder) |
| **Motor Driver**        | 1        | DRV8313 3-phase driver    | **SimpleFOC Mini**                   |
| **IMU Module**          | 1        | 6-DoF angle & gyro sensor | **DFRobot Fermion** MPU6050          |
| **DC-DC Converter**     | 1        | Voltage Step-Up for motor | **SX1308** Step-Up Module            |
| **Charge & Protection** | 1        | 1S Battery Management     | **TP4056 1A USB-C** with protection  |
| **Battery**             | 1        | Power Source              | 1S Li-Ion cell (e.g., 3.7V)          |
| **Battery Holder**      | 1        | Mount for Battery         | 1x 18650 Cell Holder                 |
| **3D Printed Chassis**  | 1 set    | Frame, Case, Mounts       | See 3D Models section                |
