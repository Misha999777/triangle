# 3D Models

All 3D models required for the Triangle robot are provided in the root `models/` directory of the repository in Fusion 360 (`.f3d`) format.

## Available Models

Click on any model to download the raw Fusion 360 file:

*   💾 **[Body.f3d](https://github.com/Misha999777/triangle/raw/refs/heads/main/models/Body.f3d)**: The main structural frame of the robot. Holds the Pico and logic boards.
*   💾 **[Case.f3d](https://github.com/Misha999777/triangle/raw/refs/heads/main/models/Case.f3d)**: The outer housing / cover.
*   💾 **[Charger Mount.f3d](https://github.com/Misha999777/triangle/raw/refs/heads/main/models/Charger%20Mount.f3d)**: Sized specifically for the TP4056 module.
*   💾 **[Motor mount.f3d](https://github.com/Misha999777/triangle/raw/refs/heads/main/models/Motor%20mount.f3d)**: Plate designed to secure the GM3506 BLDC motor to the main body.
*   💾 **[Rotor.f3d](https://github.com/Misha999777/triangle/raw/refs/heads/main/models/Rotor.f3d)**: The reaction wheel itself. Must be properly balanced.
*   💾 **[Clip.f3d](https://github.com/Misha999777/triangle/raw/refs/heads/main/models/Clip.f3d)**: A versatile mounting clip used throughout the assembly. 

## Sizing the Clip

**Important Note regarding Clip.f3d**: This single clip model is used for attaching multiple different parts (securing components to the body). You will need to **resize** this clip in depending on which specific part you are attaching.
